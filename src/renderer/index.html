触发与输入
公式与代码输入（富文本）
在答案里用 $…$ 标出数学公式（$\frac{-b\pm\sqrt{b^2-4ac}}{2a}$）、 用 ``` 三引号标出代码块，程序会把它们与普通文本分开处理。 没标记的内容一个字都不会改 —— 绝不会把 a^2 偷偷变成 a²。
公式转 Unicode：把 LaTeX 转成数学符号（√ ≤ π a² ⁻³ …）后按普通文本逐字输入， 不碰学习通界面，兼容性最好。但分数、积分这类二维排版只能写成 (-b±√(b²-4ac))/(2a) 的形式。
用学习通自带的按钮：额外去点学习通编辑器工具栏上的「公式」「代码」按钮， 在其弹窗里填内容，走它的原生排版。它依赖那个窗口把按钮暴露给无障碍接口 —— 浏览器里的学习通可以，学习通桌面客户端不行（实测客户端只暴露 1 个空面板）。 点不到时会自动退回 Unicode 输入，并在提示与日志里如实说明。
按钮名因学习通版本而异。要校准，请把学习通答题页切到前台， 在本项目目录运行 node tools/probe-uia.js --list 找到窗口，再用 --hwnd <句柄> 把该窗口的元素名导出来，按结果改上面的按钮名即可。
搜答案
图片识别（截图选题）
推荐智谱 glm-4v-flash（有免费额度、国内可直连，去 bigmodel.cn 注册拿 Key）。 不配也能用系统自带 OCR，但它会把 a² 认成 a2、3² 认成 32，搜题成功率很低。
识别之后的自动流程
打开后：截图 → 识别题目 → 搜答案 → 倒计时 → 自动切回学习通逐字输入。 倒计时期间按 Esc 或点「取消」可随时打断；输入前会先把答案写进左边大框，事后能查。
学科与选择题点选
学科由本地词法特征自动判断（不联网、不调模型），用来切换 AI 的作答规范： 数学要步骤、英语要给译文、语文要出处、物理化学要公式与配平。判断不准就在这里手动指定。
自动点选走 Windows 的 UI Automation：在窗口里找到"名字以 A./B./C./D. 开头的可选控件"并选中它， 不依赖坐标，换分辨率或字体也不会失效。默认只点选不输入文本 —— 把字母打进选择题的输入框没有意义。 它需要先识别到学习通窗口（切过去一次即可），失败时会退回"直接输入答案文本"并提示原因。
AI 解答（可选）
填一个 OpenAI 兼容接口即可。DeepSeek / 通义 / Kimi / 智谱 / OpenAI / 本机 Ollama 都走同一套协议。不填也能用本地题库和网络检索。
